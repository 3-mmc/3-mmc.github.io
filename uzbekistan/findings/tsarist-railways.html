An 1888 railway still predicts local wealth

The 1888–1906 Trans-Caspian railway still predicts local wealth 130 years later.

descriptive Real in the data, but not causally identified.

What we found

  • Across 21,382 Meta RWI grid cells, being within 20 km of the historical line = β +0.155 (p≈1e-113, ~0.37 SD), controlling for distance-to-capital and lat/lon.
  • Monotonic gradient: 0–10km +0.109 → 200km+ −0.294.
  • The railway corridor overlaps the Soviet gas trunk corridor (Bukhara→Samarkand→Tashkent), so it doubles as a proxy for the historical-infrastructure spine that set grid distribution.

Behind it: exploration/railway_rwi.py; Meta Relative Wealth Index; Trans-Caspian main line + Fergana branch station coordinates.

What this cannot carry

  • Exclusion is threatened: the railway raised income directly (that's the RWI result), so railway→income→welfare bypasses grid. Better positioned as descriptive persistence (Jedwab–Moradi / Bleakley–Lin) than as a grid-access IV.
  • Placement partly followed cotton-extraction logistics → correlated with cotton geography.
  • Controlling only distance-to-capital zeroes the coefficient (the line runs through Tashkent — collinear); the within-20km binary + lat/lon spec is the clean one.
The numbers — specification, coefficients and caveats

Claim

The 1888–1906 Trans-Caspian railway still predicts local wealth today: across 21,382 Meta RWI grid cells, being within 20 km of the historical line = β +0.155* (p≈1e-113, ~0.37 SD)**, controlling distance-to-capital and lat/lon, with a monotonic gradient (0–10km +0.109 → 200km+ −0.294). The railway corridor overlaps the Soviet gas trunk corridor (Bukhara→Samarkand→Tashkent), so it doubles as a proxy for the historical-infrastructure spine that set grid distribution — "the spatial inheritance of the Soviet subsidy state."

Backing code

exploration/railway_rwi.py:

# Tsarist railway stations (lon,lat) — main line + Fergana branch (built 1888-1906)
MAIN = [(63.58,39.08),(64.42,39.77),(65.37,40.10),(66.96,39.65),(67.84,40.12),(68.78,40.49),(69.28,41.31)]
FERG = [(69.28,41.31),(69.62,40.28),(70.94,40.53),(71.72,40.38),(72.34,40.78)]
rwi['dist_rail'] = np.minimum(line_dist(lon, lat, MAIN), line_dist(lon, lat, FERG))
rwi['near_rail'] = (rwi.dist_rail < 20).astype(int)
m = smf.ols('rwi ~ near_rail + dist_tash + latitude + longitude', data=rwi).fit(cov_type='HC1')
# near_rail beta = +0.155, p ~ 1e-113 (RWI sd = 0.42)

Caveats

  • Exclusion threatened: the railway raised income directly (that is the RWI result), so railway→income→welfare bypasses grid. Better positioned as descriptive persistence (Jedwab–Moradi / Bleakley–Lin) than as a clean grid-access IV.
  • Placement partly followed cotton-extraction logistics → correlated with cotton geography.
  • Controlling only distance-to-capital zeroes the coefficient (the line runs through Tashkent — collinear); the within-20km binary + lat/lon spec is the clean one.
